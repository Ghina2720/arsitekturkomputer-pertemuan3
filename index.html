The Instruction Cycle (Siklus F-D-E)

1. FETCH

Ambil Instruksi
➔

2. DECODE

Terjemahkan
➔

3. EXECUTE

Jalankan

(Setelah Execute, kembali lagi ke Fetch!)

Tahap 1: FETCH (Ambil)

  • CPU membaca nomor antrean di PC.
  • CPU mengambil instruksi dari RAM ➔ dimasukkan ke IR.
  • PC otomatis bertambah (+1).
PC: 100 ➔ 101
⬅️ (Tarik Data)
RAM Alamat 100

Tahap 2: DECODE (Terjemahkan)

  • Control Unit membaca isi IR.
  • Misal: Biner 1000 = Perintah ADD (Jumlahkan).
  • CU menyiapkan jalur data menuju ALU.
🧑‍💼
🤔 "1000 itu apa ya?" ➔ 💡 "Oh, Tambah!"

Tahap 3: EXECUTE (Jalankan)

  • Instruksi benar-benar dijalankan oleh ALU.
  • Perhitungan matematika diselesaikan, hasilnya disimpan.
  • Setelah selesai ➔ CPU kembali ke tahap FETCH.
⚙️
2 + 3 = 5
✅

Metronom CPU (Clock Speed)

  • Kecepatan siklus diatur oleh detak Clock (Hertz).
  • 1 GHz = 1 Miliar siklus per detik.

Mari Simulasikan!

  • Bagaimana CPU menghitung 2 + 3?
  • Ternyata CPU tidak bisa langsung menghitungnya sekaligus, butuh 3 tahap.
2 + 3 = ?

3 Langkah Program Kita

1. LOAD [10] ➔ Ambil angka 2

2. ADD [11] ➔ Tambahkan dengan 3

3. STORE [12] ➔ Simpan hasil akhirnya

Siklus 1: LOAD (Fetch & Decode)

  • CPU mengambil perintah LOAD dari RAM.
  • CU menterjemahkan: "Ambil angka di laci RAM no 10!"
IR: LOAD [10]
⬅️ (Membaca)
RAM

Siklus 1: LOAD (Execute)

  • Angka '2' ditarik dari RAM.
  • Diletakkan di Register CPU.
Register CPU
2
⬅️
RAM Laci 10
2

Siklus 2: ADD (Fetch & Decode)

  • CPU mengambil perintah ADD dari RAM.
  • CU menterjemahkan: "Jumlahkan angka di Register dengan angka di laci RAM no 11!"
IR: ADD [11]

Siklus 2: ADD (Execute)

  • ALU beraksi!
  • Angka 2 (Register) + Angka 3 (RAM) = 5.
  • Hasil 5 menimpa angka lama di Register.
ALU CPU
2 + 3 = 5
➔ Register update:
Register CPU
5

Siklus 3: STORE (Fetch & Decode)

  • CPU mengambil perintah STORE.
  • CU menterjemahkan: "Simpan isi Register (angka 5) kembali ke RAM!"

Siklus 3: STORE (Execute)

  • Angka 5 keluar dari CPU menuju laci RAM alamat 12.
  • PROSES SELESAI!
Register CPU
5
➡️
RAM Laci 12
5

Jawaban: IPC (Instructions Per Clock)

  • GHz itu cuma kecepatan lari koki.
  • Prosesor modern punya ALU lebih banyak dan Register lebih besar. Sekali lari (1 clock), dia bisa mengerjakan banyak instruksi sekaligus.

Rangkuman Pertemuan 3

  • ✅ CU (Manajer), ALU (Koki), Register (Meja).
  • ✅ PC menunjuk nomor selanjutnya, IR memegang pesanan saat ini.
  • ✅ Siklus Utama: Fetch ➔ Decode ➔ Execute.
  • ✅ Komputer menghitung secara bertahap (LOAD, ADD, STORE).
  • ✅ Clock (GHz) adalah metronom, IPC adalah efisiensi kerja.
